# IoT Traffic Analytics & DoS Detection

### Informasi Proyek
- **Judul PBL:** Pengembangan Sistem Analytic Traffic IoT untuk Deteksi Traffic Normal dan Anomali DoS
- **Kelas:** TMJ 5A

### Software
- Python
- Eclipse Mosquitto
- Tshark
- Wireshark
- Pandas
- InfluxDB
- Grafana
- Flask
- Visual Studio Code

### Fitur
- Monitoring traffic perangkat IoT
- Perekaman traffic dalam format PCAP
- Inspeksi dan analisis paket jaringan
- Pengolahan dataset traffic normal dan anomali
- Deteksi anomali DoS berbasis threshold
- Visualisasi traffic melalui dashboard
- Notifikasi anomali melalui Telegram

### Tujuan
Membangun sistem untuk memantau dan menganalisis traffic perangkat IoT serta membedakan traffic normal dengan traffic yang menunjukkan anomali DoS.
