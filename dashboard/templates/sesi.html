Cara Kerja Perekam

  1. Perekam memantau semua pesan yang sampai ke broker (subscribe iot/#) — sumber yang sama dengan analyzer.
  2. Setiap pesan ditulis sebagai paket MQTT-PUBLISH valid (Ethernet/IP/TCP lengkap dengan checksum, MAC & IP node asli dari devices.json) ke captures/<label>.pcap — bisa dibuka langsung di Wireshark.
  3. Sekaligus dihitung metrik window 1 detik per perangkat — skema sama dengan dataset_BASE.csv — disimpan ke data/dataset_<label>.csv saat sesi dihentikan.
  4. Dataset siap dipakai: python scripts/plot_compare.py data/dataset_BASE.csv data/dataset_S1.csv atau kalibrasi ulang threshold dari menu Pengaturan.
Kenapa PCAP tidak pernah kosong? Perekam lama bergantung pada tshark/Wireshark + hak admin + pemilihan interface — bila tidak terpasang, file .pcap kosong (bug v9.2.1). Perekam baru ini murni Python: nol dependensi, dan malah lebih lengkap — serangan dari web yang lewat loopback ikut terekam (tidak terlihat oleh capture NIC biasa).
